# Lead Management System

A full-stack Lead Management System built using React.js, Node.js, Express.js, and PostgreSQL.

## Features
* Add Leads
* View Leads
* Update Lead Status
* Delete Leads
## Tech Stack
### Frontend
* React.js
* Axios
* CSS
### Backend
* Node.js
* Express.js
### Database
* PostgreSQL
## Installation
### Frontend
cd frontend
npm install
npm run dev
### Backend
cd backend
npm install
node server.js

Create PostgreSQL database and table using the provided SQL query.
